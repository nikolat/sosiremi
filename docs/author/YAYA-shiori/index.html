# 改造のしかた

紺野ややめは、SHIORI「YAYA」で自分のゴーストを作るための土台（テンプレート）です。辞書を編集して、自分のゴーストを作ってください。

## 手で編集する

- 辞書の本体は `ghost/master/dic/normal/` にある `.dic` ファイルです。文字コードは UTF-8（BOM なし）です。
- どのファイルに何が書いてあるか（ランダムトーク、起動・終了、マウスへの反応、メニューなど）、キャラクターと使えるサーフェス番号、トークの書き方の決まりは、[GHOST.md](GHOST.md) にまとめてあります。
- 詳しい仕様は、次を見てください。
  - YAYA の文法と関数: yaya-docs（https://yaya-shiori.github.io/yaya-docs/ ）
  - さくらスクリプト、SHIORI イベント、設定ファイル: UKADOC（https://ssp.shillest.net/ukadoc/manual/ ）
- 辞書にエラーがあると、ゴーストは緊急モードで起動し、ほとんど話さなくなります。
- シェル（`shell/master/`）は SATO M 氏の作品で、CC BY-NC-ND 2.1 JP です。画像を改変したものは配布できません。
- 自分のゴーストとして配布するときに変えるところ（名前、作者、インストール先、ネットワーク更新の URL など）は、[GHOST.md](GHOST.md) の「テンプレートから独立させるときの追加項目」にチェックリストがあります。

## AI エージェントで開発する

AI コーディングエージェント（Claude Code、Codex など）で開発するときは、スキル [ukagaka-developer](https://github.com/ukatech/ukagaka-developer) が使えます。このゴーストの SHIORI（YAYA）に合わせて、辞書の書き方、エラーのチェック、SSP での動作確認、シェル画像の編集、nar の作成、SHIORI の更新を手伝ってくれます。スキルは、このフォルダの外に入ります。

Claude Code の場合は、このフォルダで次を実行して、Claude Code を開き直します。

```
claude plugin marketplace add ukatech/ukagaka-developer
claude plugin install ukagaka-developer --scope project
```

Codex など、ほかのエージェントでの入れ方と、使い方は、[ukagaka-developer の README](https://github.com/ukatech/ukagaka-developer#readme) にあります。入れたら、「セットアップして」と頼んでください。ゴーストに固有の情報は、リポジトリの [GHOST.md](GHOST.md) にまとめてあります。

## Sound Player Ghost "FLELE"

![サムネイル](https://raw.githubusercontent.com/YAYA-shiori/flele_aya/master/thumbnail.png)

## [ダウンロード](https://github.com/YAYA-shiori/flele_aya/releases/latest/download/flele_aya.nar)

## 使い方

[SSP](https://ssp.shillest.net/) の最新版で正常に動作します。

以下の説明で、**マウス**はマウス操作、**キー**はキー操作です（キーは、ヘルプメニューのキー設定から変更できます）。
FLELE がアクティブなときは、指定のキーを押すだけで実行されます。インアクティブなときは `Shift` + `Ctrl` と一緒に押してください。
シェルの当たり判定にマウスカーソルを合わせると、その操作の説明がツールチップで出ます。

### 曲リストに曲を追加する

- **マウス**: サウンドファイルを FLELE にドロップ
  - 複数のファイルをまとめて、フォルダごと、m3u 形式の曲リストファイルをドロップして追加することもできます。

### 曲をダウンロードして曲リストに追加する

- **マウス**: ウェブ上のサウンドファイルのリンクを FLELE にドロップ、またはヘルプメニューの「URL入力DL」から URL を直接入力

曲データをダウンロードして曲リストに追加します。ダウンロードしたファイルは `sound_file` フォルダの中にあります。
これは一時的なもので、曲リストのクリアと同時に削除されます。削除したくないファイルは別の場所にコピーしておいてください。

### 基本の操作

| 操作 | マウス | キー |
|------|--------|------|
| サウンド再生 | 胸ボタンをクリック | `R` |
| 再生の一時停止 / 解除 | 髪留めをクリック | `S` |
| ヘルプメニューを出す / 閉じる | FLELE の体（右手・足・胸・髪留め以外）をダブルクリック | `M` |
| 曲リストを出す | FLELE が左手に持っているファイルを右クリック | - |
| 次の曲を演奏 | 次の曲ボタンをクリック（シェルによる） | `N` |
| 前の曲を演奏 | 前の曲ボタンをクリック（シェルによる） | `B` |
| 曲名ウィンドウを出す / 閉じる | 右手のグローブをダブルクリック | `W` |
| 曲リストを全てクリア | 靴をダブルクリック | `C` |
| 終了する | 右クリックメニュー > 終了 | `E` |
| 外見（シェル）を変更する | 右クリックメニュー > シェル | - |

- **サウンド再生**: 曲リストの中から曲を選んで再生します。もう一度押すと選び直して再生します。選び方は、そのとき設定している再生法によって変わります。
- **一時停止 / 解除**: 演奏中の曲を一時停止します。もう一度押すと、止めたところから再生します。
- **ヘルプメニュー**: もう一度押すと閉じます。
- **次の曲 / 前の曲**: 再生方法に関係なく、曲リストの順に次の曲・前の曲を演奏します（最後の曲の次は最初の曲、最初の曲の前は最後の曲）。ボタンはシェルによってはありませんが、キー操作はどのシェルでも使えます。
- **曲名ウィンドウ**: 演奏中の曲名を案内するウィンドウです。もう一度押すと閉じます。
- **外見変更**: 音楽プレイヤーでいうスキンのようなものです。同梱されていないシェルは、FLELE の配布サイト（サービス終了）からダウンロードできました。シェルによってクリックする場所が変わる場合があるので、ご注意ください。

### 補足

#### 再生できないファイル

FLELE は音楽の再生を SSP 本体に任せています。環境によって再生できない場合があります。再生できないファイルは、SSP のエラーログに出る案内（コーデックの追加など）を参考にしてください。
連続再生中に再生できない曲があったときは、その曲を飛ばして次の曲を演奏します。

#### 曲タイトル表示

曲名などのタグは、SSP 本体を通して Windows の機能で読んでいます。Windows が読めない形式やタグでは、曲名の代わりにファイル名を表示します。

#### プレイボタンを押したときに演奏される曲

- 「同じ曲をエンドレス再生」モード: 直前に演奏した曲（初演奏はランダム）
- 「リスト順に一周だけ再生」モード: リスト中の曲番号 1 の曲
- 他のモード: ランダム

#### 音楽ファイルのダウンロード

- 同じファイル名の曲が既にある場合は上書きします（上書きするときに確認があります）。要望があれば、ファイル名が被ってもダウンロードできるようにします。その場合は「元のファイル名 + 時刻」のファイル名になると思います。
- ダウンロードしたあとにセーブデータが消えると、ダウンロードした曲が残ったままになります。その場合はお手数ですが、手動で削除してください。

#### 曲リストメニュー

- たまに出てこないことがあるようです。ゴーストの再起動（それでも出ないときは PC の再起動）で直るはずです。
- ファイル名ではなく曲タイトルを表示させるのは、曲数が多いとかなり重くなるので無理そうです。

#### コミュニケート

他のゴーストから、「音楽」「サウンド」「曲」のどれかと、「再生」「演奏」「かけて」「歌って」のどれかの言葉で話しかけられると、曲を演奏します。プレイボタンを押したときと同じ効果で、演奏中でも反応します。

#### 音量調節

曲リストメニュー（FLELE が左手に持っているファイルを右クリック）の「volume」から、0〜100 の音量を 10 刻みで選べます。演奏中でも、その場で音量が変わります。
曲リストメニューを使わない設定にしているときは、ヘルプメニューの「設定」>「音楽再生の設定」で、［－］［＋］を押して調節します。
SSP 本体のサウンドの音量（`--volume`）を変えるもので、パソコン全体の音量は変わりません。

#### 表示言語（English）

SSP の言語設定に合わせて、メニューやメッセージの言語が自動で切り替わります（日本語 / English）。
SSP を日本語以外で起動したときや、言語リソースを日本語以外に切り替えたときは、英語で応えます。
言語を追加するための仕組みもあります。詳しくは `GHOST.md` の「表示言語」を見てください。

The menus and messages follow the language of SSP. When SSP runs in a language other than Japanese, or you switch the language resource to one, FLELE answers in English. (This manual is still in Japanese only.)

#### トーク

もともとトークの無いゴーストにしようと思って作ったので、これ以上増えないと思います。

#### シェル

- FLELE のシェル仕様は、master シェル（Lime）の `readme.txt` に書いてあります。
- Sorcerer-F と Button は着せ替え付きです。
- おすわりシェルを縮小すると体が浮くときは、シェルのフォルダ内の `makoto.dic` をテキストエディタで開き、30 行付近の `//y座標差分` の下にある `'-128',/` の「-128」の数値を調節してください。

#### スクリーンショット

SSP 本体の設定で透明度をオフにすると撮影できるようになるようです。

#### FLELE を増やす

`ghost` フォルダ内にある `flele_aya` フォルダをコピーすると増やせます。
同じタイトルのゴーストが増えて紛らわしくなるので、「増やしたフォルダ\ghost\master\descript.txt」内の `name,FLELE` の `FLELE` を適当な名前に書き換えるとよいでしょう（ネットワーク更新すると元に戻ります）。
複数の FLELE を同時に起動すると、音楽再生ができなくなってしまうことがあります。

### 注意とおすすめ

- 動作がおかしくなったときは、いったん終了して、`ghost/master` フォルダ内の `yaya_variable.cfg` と `profile` フォルダを削除してみてください。
- 右クリックメニューから「ネットワーク更新」をかけると最新版になります。不具合が直ったり、機能が増えたりするかもしれません。
- SSP の設定で「常に手前に表示」にしておくのをおすすめします。

スタンプ帳　version 1.4.1

これはゴーストのスタンプを収集するSSP専用プラグインです。
あまり古すぎるSSPには対応していません。


最初はまっさらなスタンプ帳があるだけです。
対応しているゴーストから押してもらってください。
スタンプを押してもらえるゴースト一覧はこちらです。
 > http://www10.atwiki.jp/postic/pages/13.html


スタンプはゴースト一体につき一つまでです。
貰える条件はそのゴーストによって違います。
出会ってすぐにあっさり押して貰えるかもしれませんし、なかなか貰えないかもしれません。

押してもらったスタンプは
右クリックメニュー＞プラグイン＞スタンプ帳
で確認できます。
小さいバルーンでは上手く表示されません（対応法考え中）

よくわからない方はこちらの解説が詳しいのでぜひ。
http://d.hatena.ne.jp/hinoharu/20080507#1210173143




ほか、細かいこと。

■スタンプを削除する
スタンプは追加、上書きされるだけで削除はできません。
どうしても一旦初期化させたい場合はゴーストが起動していない状態でssp.exeと同じ位置に存在する「plugin」内「stampcollection」フォルダを開き、「YAYA_variable.cfg.ays」を削除すれば元のスタンプが1つもない状態に戻ります。

■スタンプをバックアップする、他のSSPに移動する
ssp.exeと同じ位置に存在する「plugin」内「stampcollection」フォルダを、移動先SSPの同じ位置にコピーすると移動できます。
（スタンプのデータは「YAYA_variable.cfg.ays」と「icon」フォルダの中身全てです）
バックアップする場合はこのフォルダをどこか別な場所にコピーして保管しておいてください。

■スタンプをネットワーク更新する
エクスプローラーを開き、「種類」を「プラグイン」にし、スタンプ帳項目右クリックからできます。
（それ以外の方法もあるのかもしれませんがよくわかりません）

■スタンプ帳プラグインの扱いについて
再配布・ゴーストに同梱配布可、改変配布可です。
（2013/12/28　改変配布不可より可に変更））
